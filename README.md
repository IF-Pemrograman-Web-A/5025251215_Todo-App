## Deskripsi
# Todo App - E02 (The JavaScript Dungeon)

## Fitur yang Diimplementasikan:
1. **DOM Manipulation:** Menangkap input dari form dan langsung menampilkannya ke dalam list tanpa me-refresh halaman.
2. **Interaksi CRUD:** Terdapat tombol Edit, Delete, dan Checkbox untuk menandai tugas selesai (Completed/Pending).
3. **Data Object:** Data disimpan dalam bentuk array of objects pada variabel JavaScript. Sesuai instruksi, data akan kembali ke *default* saat halaman di-refresh.
4. **Event Handler:** Menggunakan `addEventListener` untuk menangani *submit* form, klik tombol, dan perubahan checkbox.
5. **Toggle Class:** Mengimplementasikan fitur Light/Dark Mode menggunakan `classList.toggle('dark')`.
