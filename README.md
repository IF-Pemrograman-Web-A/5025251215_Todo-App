## Deskripsi
Pada halaman Todo List ini terdapat beberapa bagian, yaitu:

- Header yang berisi judul "My Todo List" dan keterangan singkat.
- Bagian Tasks yang menampilkan beberapa daftar tugas beserta statusnya.
- Setiap tugas memiliki nama, deskripsi singkat, dan status seperti Pending atau Completed.
- Bagian New Task yang berisi form untuk memasukkan nama dan deskripsi tugas baru.
- Bagian Task Details yang menampilkan detail dari salah satu tugas, seperti nama, deskripsi, dan status tugas.
- Terdapat tombol Save Changes dan Delete Task pada bagian detail tugas.
