# Todo App - E04 The Iron Citadel

## Fitur yang Diimplementasikan:
1. **Menu Bar / Side Bar:** Menambahkan menu navigasi "Personal" dan "Shared" untuk memisahkan daftar tugas berdasarkan tipenya.
2. **Migrasi ke PHP & Modular:** Mengubah struktur HTML statis menjadi file PHP modular (`config.php`, `index.php`, `add.php`, `edit.php`, `delete.php`).
3. **Database Setup (`data.sql`):** Membuat struktur database MySQL (`todo_e04`) dengan tabel `tasks` beserta data dummy yang disimpan dalam file `data.sql`.
4. **CRUD Menggunakan PHP:** Mengimplementasikan fungsi Create, Read, Update, dan Delete menggunakan PDO (PHP Data Objects) untuk interaksi ke database.
5. **File Handling:** Mengimplementasikan fungsi `file_put_contents()` untuk mencatat log setiap kali ada tugas baru yang ditambahkan ke dalam file `log.txt`.
